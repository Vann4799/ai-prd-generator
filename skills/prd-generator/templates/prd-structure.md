# PRD Template

Use this template for consistent PRD generation.

## Structure

```markdown
# [Project Name] PRD

## 1. Project Overview
- **Project Name**: [name]
- **Description**: [1-2 sentences]
- **Version**: [version]
- **Date**: [date]
- **Author**: [author]

## 2. Problem Statement
[Describe the problem, why it matters, current pain points]

## 3. Target Users
- **Primary**: [persona 1]
- **Secondary**: [persona 2]
- **Needs**: [user needs]
- **Goals**: [user goals]

## 4. Features

### Must-Have (P0)
- [ ] [Feature 1]
- [ ] [Feature 2]

### Should-Have (P1)
- [ ] [Feature 3]
- [ ] [Feature 4]

### Nice-to-Have (P2)
- [ ] [Feature 5]

## 5. User Stories

### [Feature 1]
- **As a** [user]
- **I want** [feature]
- **So that** [benefit]
- **Acceptance Criteria**:
  - Given [context], when [action], then [outcome]

## 6. Technical Requirements
- **Tech Stack**: [stack]
- **Platform**: [platform]
- **Dependencies**: [dependencies]
- **Performance**: [requirements]

## 7. Success Metrics
- **KPI 1**: [metric] — Target: [value]
- **KPI 2**: [metric] — Target: [value]

## 8. Timeline
- **Phase 1**: [dates] — [deliverables]
- **Phase 2**: [dates] — [deliverables]
- **Launch**: [date]

## 9. Risks & Mitigation
| Risk | Impact | Mitigation |
|------|--------|-----------|
| [risk 1] | [high/med/low] | [strategy] |
| [risk 2] | [high/med/low] | [strategy] |

## 10. Appendix
- [Additional notes]
- [References]
```

## Usage
1. Fill in all sections based on interview
2. Ensure all sections are complete
3. Format as markdown
4. Export to requested format
