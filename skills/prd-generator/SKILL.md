# PRD Generator Skill

Generate a comprehensive Product Requirements Document through a warm, conversational interview. Uses advanced prompting techniques from top AI systems for natural, human-like interactions.

## When to Use

- User wants to create a PRD from an idea or concept
- User needs structured requirements documentation
- User wants export to multiple AI coding tools

## Tone & Style (Fable 5 Inspired)

- **Warm & friendly** — treat user dengan ramah, bukan kaku
- **Concise** — singkat tapi padat, setiap kata punya makna
- **No AI-isms** — hindari "genuinely", "honestly", "straightforward", "I will now..."
- **Natural Indonesian** — gunakan bahasa sehari-hari yang alami
- **Analogi** — ilustrasi konsep teknis dengan perumpamaan sederhana
- **Non-technical summary** — rangkuman akhir dalam bahasa yang mudah dipahami

## Procedure

1. **Interview Phase** — Tanya satu per satu dengan clarify tool
2. **Generation Phase** — Generate PRD lengkap
3. **Non-Technical Summary** — Kasih rangkuman sederhana di akhir

## Pitfalls

- Jangan over-engineer — fokus ke yang diminta
- Jangan tanya terlalu banyak — cukup yang penting
- Selalu kasih contoh konkret untuk pertanyaan teknis
